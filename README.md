# 📄 AI Resume & Career Advisor

AI-powered tool that analyzes a resume against a specific job description and tells you exactly where you stand. Upload both PDFs and get a match score, matched/missing skills, a 4-week improvement roadmap, and interview tips — all generated by two cooperating AI agents. Built as a college AI project combining RAG and multi-agent design.

## 🛠️ Technologies

- Python
- Streamlit
- pdfplumber
- ChromaDB
- sentence-transformers
- Groq API (Llama / GPT-OSS)
- python-dotenv

## ✨ Features

Here's what you can do with AI Resume & Career Advisor:

- **Upload & Analyze**: Upload a resume and a job description as PDFs and get an instant AI-powered fit analysis.
- **RAG-powered matching**: The job description is chunked and only the most relevant sections are retrieved for analysis, instead of sending the whole document to the LLM.
- **Match Score**: Get a 0-100 score showing how well the resume fits the role.
- **Skill Gaps**: See exactly which skills matched and which are missing.
- **4-Week Roadmap**: A Career Advisor agent turns the gaps into a concrete, week-by-week improvement plan with interview tips.
- **3-Month Learning Plan**: An optional stretch-goal agent builds a longer-term learning path on demand.
- **Privacy-aware output**: The candidate's name never appears in the AI-generated analysis — it always refers to "the candidate."

## ⏳ The Process

1. **PDF extraction**: Both files are parsed into plain text with `pdfplumber`, chosen over `pypdf` because it handles multi-column resumes more reliably.
2. **Chunking + embedding**: The job description is split into ~300-word overlapping chunks, embedded locally, and stored in an in-memory ChromaDB collection.
3. **Retrieval**: The resume text is used as a query to pull the top 4 most relevant job description chunks.
4. **Resume Reviewer Agent**: A structured prompt asks the model to return strict JSON — score, matched skills, missing skills, weak areas, and a summary.
5. **Career Advisor Agent**: Takes the reviewer's JSON output as input and builds a roadmap and interview tips — one agent's output becomes the next agent's context.
6. **UI rendering**: Streamlit displays the score as a progress bar, skills as two columns, and the roadmap as expandable sections.

The biggest real-world hurdle wasn't the AI logic — it was environment setup: installing Python and getting it onto PATH, fixing a `pip install` that silently failed due to the wrong terminal directory, and switching LLM providers twice (OpenAI → Gemini → Groq) after hitting billing and rate-limit walls on free tiers.

## 🎓 What I Learned

- How to design a RAG pipeline from scratch: chunking strategy, why overlap matters, and how embeddings retrieve by *meaning* instead of keyword matching.
- How to chain two LLM agents so one's structured output becomes the next one's input.
- Why `temperature` and forcing JSON output (`response_format`) matter for consistent, parseable LLM results.
- Streamlit's rerun model — every interaction re-executes the whole script — and why `session_state` is necessary to persist results.
- That LLM APIs aren't interchangeable in practice: quotas, deprecated models, and billing requirements varied a lot between providers.
- Practical environment debugging: PATH issues, silent `pip install` failures, and why `.env` + `.gitignore` matter for keeping API keys out of version control.

## 🚀 How Can It Be Improved?

- **Persist the vector store**: ChromaDB currently runs in-memory, so the job description is re-indexed on every run.
- **Support more file types**: currently PDF-only; `.docx` resume support would help.
- **Multi-JD comparison**: compare one resume against several job descriptions at once.
- **Reduce output variance**: self-consistency (averaging multiple samples) could tighten score variance across repeated runs.
- **Add authentication and history**: save past analyses per user.
- **Deploy publicly**: currently local-only; Streamlit Community Cloud would make it shareable via a link.

## ▶️ Running the Project

1. Clone this repository and open it in your editor.
2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Get a free Groq API key (no card required) at [console.groq.com/keys](https://console.groq.com/keys).
4. Create a `.env` file in the project root (copy `.env.example`) and add your key:
   ```
   GROQ_API_KEY=your-key-here
   ```
5. Run the app:
   ```
   streamlit run app.py
   ```
6. Open the local URL Streamlit prints (usually `http://localhost:8501`), upload a resume and a job description PDF, and click **Analyze**.
